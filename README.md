# 🐾 PetRelief Portal

A responsive and interactive pet care and adoption website developed using **HTML, CSS, JavaScript, Firebase, and APIs**. The platform helps users explore pet adoption, donations, volunteering opportunities, and multiple pet care services including grooming, training, medical support, boarding, and dog walking.

# 🌟 Features

- Responsive Design
- Interactive User Interface
- Pet Adoption System
- Donation Platform
- Volunteer Registration
- Pet Care Services
- Smooth Navigation
- Mobile-Friendly Layout
- Firebase Integration
- API Integration
- Dynamic Content Loading
- Organized Folder Structure
- GitHub Hosted Website


# 📂 Website Pages

## 🏠 Main Pages

### `index.html`
Landing page introducing the website with quick navigation to all sections and services.

### `home.html`
Displays featured pets, banners, announcements, and highlighted services.

### `about.html`
Provides information about the website, mission, vision, and project purpose.

### `contact.html`
Contains contact details, social media links, location information, and inquiry forms.

### `resources.html`
Includes pet care guides, FAQs, blogs, and useful resources for pet owners.


# 📊 Dashboard Section

### `dashboard.html`
Central navigation page connecting users to adoption, donation, volunteering, and service pages.


# 🐶 Core Features

### `adoption.html`
Allows users to browse pets available for adoption with details and adoption information.

### `donation.html`
Provides donation options to support rescue and welfare activities.

### `volunteer.html`
Enables users to register for volunteering activities and rescue programs.

### `service.html`
Displays all pet-related services provided by the platform.

# 🐾 Services Provided

### `boarding.html`
Pet boarding facilities for safe and comfortable temporary stays.

### `dogwalk.html`
Professional dog walking services for pet exercise and care.

### `mating.html`
Responsible pet mating and breeding assistance.

### `medical.html`
Veterinary services including vaccinations, checkups, and treatments.

### `training.html`
Pet obedience and behavior training programs.

### `grooming.html`
Pet grooming services including bathing, trimming, and hygiene care.
